# 🏳️ Flagg
## Swift Student Challenge 2025 (WWDC25)

Flagg is an beginner-friendly educational iPadOS app that help users strengthen geographical knowledge. It offers engaging, interactive gameplay using flags, landmarks, and cities designed to build better memory through relevant hints and repetition.
